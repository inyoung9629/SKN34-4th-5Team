# 코스 교체 선택 답변과 장소 링크 검증

## 변경 배경

기준은 팀 `upstream/develop`의 `718b99c`를 반영한 작업 브랜치 `feat/remove-sbiz-data`, 변경 전 HEAD는 `6ac1bf5`다. 팀의 질문 선택 UI와 신규 출처 검색 제한 정책을 유지한다.

기존 코스에서 “식당이 좀 별로다. 돈카츠 가게로 수정해줘”라고 요청하면 FOOD 방문이 둘이라 교체 대상을 묻는다. 선택창의 “1번 STATION” 답변은 질문 문구와 합쳐져 전송된다. 기존 단순 수정 해석기는 이 형식을 지원하지 않아 의미 해석·추가 근거 검증으로 넘어갔다. 돈카츠 업종 후보가 있었지만 신규 출처 검색 제한과 만나 후보를 모두 탈락시켰다. 주변에 돈카츠 가게가 없는 상황이 아니었다.

## 변경

- 선택 답변을 직전 사용자 요청 전체 및 마지막 확인 질문에 연결한다. 현재 코스의 번호·상호가 일치하는 단일 방문만 교체한다. 특정 상호나 구장으로 분기하지 않는다.
- 원 요청 전체를 단순 교체 문법으로 소비할 수 있을 때만 기존 빠른 수정 경로를 사용한다. 주차·알레르기·내부 매장·설명 요청, 추가 답변, 모호하거나 오래된 선택은 기존 의미 해석을 유지한다. 저장된 브랜드 충돌, 고정·완료 방문 보호도 유지한다.
- 일반 추천 모드의 기존 돈까스 상호·전문 업종 기준을 재사용한다. 메뉴판을 새로 확인했다고 주장하지 않는다. 명확한 후보가 없는 경우의 근거 검증도 유지한다.
- 서버가 현재 코스에 있는 장소 URL을 선택지의 `choice_links`로 붙인다. 자리어때는 “매장 상세 위치”, 그 외는 “장소 정보”다. URL이 없거나 동명·번호 불일치로 식별이 안 되면 링크를 만들지 않는다.
- 링크는 선택 버튼 밖의 작은 박스로 표시하며 새 창에서 연다. 링크 클릭은 선택 답변을 보내지 않는다. 기존 문자열 선택지·직접 입력·이력 형식은 호환된다. 링크 때문에 추가 검색이나 모델 호출을 하지 않는다.

## 실제 API 확인

사용자 대화를 복사한 별도 테스트 게스트 세션에서 동일 입력으로 `/api/v2/chat/sessions/{id}/messages/` 완료 이벤트까지 측정했다. 원 사용자 대화와 지도는 변경하지 않았다. 날짜는 2026-10-16 광주 14:00이며 동일 출발지·기존 코스를 사용했다. 프록시·브라우저 시간은 제외한다. 운영 캐시는 유지했고 각 조건 1회 측정이다.

| 조건 | 시간 | 결과 | 계측된 모델 호출 |
| --- | ---: | --- | --- |
| 수정 전 선택 답변 | 41.704초 | 코스 없음, 교체 실패 | JEV 분류 1회 + gpt-6-luna 2회 |
| 수정 후 같은 선택 답변 | 6.213초 | 블랙모밀 광주본점으로 교체 성공 | JEV 분류 1회 |
| 수정 후 선택창 생성 | 16.892초 | 두 선택지에 실제 매장 URL 포함, 코스 변경 없음 | JEV 분류 1회 + gpt-6-luna 3회 |

수정 후 선택 답변은 대상 변경, 외부 식당 사용, 나머지 방문의 이름·ID·종류·좌표·체류시간 보존, 경기 날짜·시각 및 출발지 보존을 모두 통과했다. 내부 먹거리에서 외부 식당으로 바뀌면서 일반 구장 도착 시각은 경기 시작 20분 전인 13:40으로 재계산됐다. 음식점은 돈까스 전문 업종 근거이며 현재 메뉴 판매 여부를 실시간 확인한 결과는 아니다.

선택창 API 결과는 STATION의 자리어때 상세 URL 및 파쿠야 용봉점의 카카오 장소 URL을 정확히 반환했다. 질문 생성과 선택 후 수정은 서로 다른 요청이므로 시간을 합치거나 동일 단계로 비교하지 않는다. 실패 1회와 성공 1회의 비교이므로 평균 개선율·장기 성공률·최대 응답 시간 보장으로 해석하지 않는다.

## 회귀 검사

- 새 선택 연결·선택 UI 백엔드 검사 19개 통과
- 성능 지침의 코스 생성·병렬 조회·수정·조건·거리·취소·숙박·최종 응답 검사 161개 통과
- 통합 183개 최초 실행에서 새 단위 테스트의 일반 추천 모드 설정 누락으로 1개 테스트가 오류/실패했다. 테스트에 운영 모드를 명시하고 위 19개 및 161개를 재실행해 통과했다. 나머지 통합 검사는 통과했다.
- 프론트엔드 전체 735개: 733개 통과, 기존 2개 건너뜀, 실패 0개

- 실제 컴포넌트와 CSS를 렌더링한 임시 페이지에서 버튼 아래 URL 박스 배치를 확인했고 임시 공개 파일은 제거했다. 링크 클릭 시 답변이 전송되지 않는 동작은 컴포넌트 테스트로 확인했다.
