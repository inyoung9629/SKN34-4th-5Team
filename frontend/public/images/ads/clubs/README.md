# Club mock carousel artwork

These are composed SVG banners, not official club advertisements. Each desktop/mobile
file contains its own background, text and embedded original club logo, with no
runtime remote image requests. Logos belong to their respective owners.

- Logo source: TVING public team SVGs documented in ../../teams/README.md.
  All ten source URLs were checked successfully on 2026-10-02.
- Rebuild: from frontend, run node scripts/generate-club-banners.mjs.
- Club metadata and Instagram URLs: frontend/lib/club-ads.ts.
- Banner copy is demo copy, not an official club slogan or commercial partnership.
