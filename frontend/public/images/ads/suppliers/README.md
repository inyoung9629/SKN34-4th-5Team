# 유니폼·용품 브랜드 목업 광고

확인·다운로드: 2026-10-02. 사진 원본은 source/*.img에 저장되며 실제 MIME은 배너 생성기가 판별한다.
PC/모바일 SVG는 원본 사진 바이트를 data URI로 그대로 포함하는 독립 이미지다.
외부 이미지 핫링크, 가격·할인·재고 보장, 실제 서비스와의 제휴 주장은 사용하지 않는다.
공개 배포 전 이미지 사용 권한과 최신 후원 관계를 확인해야 한다.

## 노출 기준

브랜드(광고주) ID당 한 장. 같은 브랜드가 복수 구단을 후원하면 teams/teamCodes를 합쳐 한 번 노출한다.
현재 확인한 10개 구단의 대표 유니폼·용품 후원 브랜드는 모두 다르다.
상품화 대행사/판매점/OEM 공장 기준이 아니라 화면에 광고되는 제공 브랜드 기준이다.
선수 개인 후원사나 모든 보조 용품 업체를 망라한 목록은 아니다.
